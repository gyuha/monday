# monday

monday는 팀이 직접 호스팅하는 데몬이다. 등록된 디렉토리마다 에이전트 팀을 배치해 실행하고, 웹·텔레그램·슬랙으로 제어한다. paseo를 포크해 만들었다.

## Language

**디렉토리**:
관리자가 등록하는 작업 단위다. 루트 경로 하나에 대응하며, 에이전트 팀과 접근 허용 목록이 여기에 붙는다. paseo의 Project에 해당한다. 그 아래에 있는 worktree나 Workspace는 같은 팀과 같은 권한을 공유한다.
_Avoid_: 폴더(일상어로는 허용), 프로젝트(paseo 내부 용어와 혼동), 워크스페이스

**프로바이더 항목**:
에이전트를 실행하는 데 쓰는 이름 붙은 설정이다. 에이전트 CLI/SDK 종류와 자격증명(env)을 묶어 둔다. 예: `claude`, `claude-홍길동`. 계정은 사용자가 아니라 프로바이더 항목에 붙는다.
_Avoid_: 계정, 프로필(paseo의 Agent profile과 다름)

**대화**:
사용자가 디렉토리에 일을 시키는 하나의 맥락 단위다. 웹 세션 하나, 또는 메신저 스레드/토픽 하나가 대화 하나다. 대화마다 오케스트레이터가 하나씩 새로 뜬다.
_Avoid_: 세션(프로바이더 세션과 혼동), 채팅

**역할**:
팀 구성 안에서 이름이 붙은 서브에이전트 정의다. 프롬프트와 프로바이더 항목을 갖는다. 오케스트레이터가 작업마다 역할의 인스턴스를 띄운다.
_Avoid_: 에이전트 프로필(paseo의 Agent profile과 다름)
