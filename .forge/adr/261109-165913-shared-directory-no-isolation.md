# 같은 디렉토리의 대화들은 격리 없이 한 폴더를 공유한다

대화마다 새 오케스트레이터가 뜨고 대화들은 동시에 돈다. 그래도 모든 대화와 서브에이전트는 디렉토리의 같은 폴더에서 실행한다(paseo의 Local isolation). 대화마다 git worktree를 따로 만드는 방식은 쓰지 않는다.

worktree로 격리하면 충돌은 막을 수 있다. 하지만 대화 결과를 본 브랜치에 합치는 흐름을 따로 설계하고 운영해야 하고, git이 아닌 디렉토리에는 적용할 수도 없다. 그래서 단순함을 택했다.

다만 에이전트가 판단해서 스스로 worktree를 만드는 것(paseo `create_workspace` MCP)은 막지 않는다(2026-11-09 추가 결정). 이렇게 생긴 worktree의 결과를 본 폴더에 합치는 일은 사용자가 한다. 이 제품이 기본으로 격리하지 않는다는 뜻이지, 격리를 금지한다는 뜻은 아니다.

대가는 두 대화가 같은 파일을 동시에 고치면 한쪽 변경이 사라질 수 있다는 점이다. 이 위험은 감수하고 운영으로 피한다. 잠금이나 경고 같은 보완책은 필요해지면 따로 결정한다.
