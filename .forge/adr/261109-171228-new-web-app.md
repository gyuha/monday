# 웹 화면은 paseo 앱을 고치지 않고 새로 만든다

monday의 웹앱(사용자 화면과 관리자 메뉴)은 새 웹앱으로 만든다. paseo의 `packages/app`(Expo, 웹 빌드 지원)을 개조하지 않는다.

paseo 앱에는 이미 대화, 서브에이전트 트랙, 터미널 화면이 있어서 이를 재사용하면 수개월을 아낄 수 있다. 그런데도 새로 만드는 이유는 다음과 같다.
- paseo 앱은 소유자 한 명을 전제로 설계되었다. 호스트 연결 정보를 클라이언트에 저장하고, 모든 프로젝트를 다 보여준다.
- 다중 사용자 로그인과 디렉토리별 필터링을 넣으려면 앱 고유 코드를 광범위하게 고쳐야 한다. 그러면 upstream 병합 비용이 커진다.
- Expo 웹은 폼이 많은 관리자 화면에는 무겁다.

대가로 대화, 서브에이전트, 파일, 터미널 UI는 직접 다시 구현해야 한다.
