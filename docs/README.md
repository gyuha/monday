# docs

설계 결정의 정본. 코딩 에이전트는 이 폴더를 근거로 구현한다 (`AGENTS.md` 참고).

## 구성
- `product.md` — 제품 개요(대상, 배포 형태, 핵심 개념)
- `architecture.md` — 기반과 패키지 구조
- `research/` — 외부 프로젝트 조사 결과
  - `paseo-hermes.md` — paseo(데몬·프로바이더)와 Hermes(메신저 게이트웨이) 분석

결정이 확정될 때마다 이 목록에 문서를 추가한다. 각 결정의 "왜"는 `.forge/adr/`에 기록하고 여기서 링크한다.
